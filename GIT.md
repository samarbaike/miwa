**useful commands**

| git add | to select which changes goes to next commit |
| git commit -m "blah blah blah" | to save snapshot/comment on the committed changes to history |
| git push | to push the changes to remote origin |
| git clone URL | Download a repository and its history |
| git remote -v	| Show configured remote repositories |
| git fetch	| Download remote updates without integrating them |
| git pull | Fetch remote changes and integrate them into your current branch |
| git push	| Upload your commits |
